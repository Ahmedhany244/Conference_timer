📖 Testing Instructions

🎯 How to Fix "User has already checked in" Error:

  1. Option 1: Use different users for testing (User 1 and User 2)
  2. Option 2: Clear specific user's data using the form above
  3. Option 3: Clear all test data and start fresh
  4. Option 4: Use different events for the same user

🔄 Testing Flow:

  1. Login as Admin here
  2. Clear any existing test data
  3. Go to QR Test Page
  4. Generate QR as User 1, scan as Admin
  5. Generate QR as User 2, scan as Admin
  6. Test admin controls on Admin Dashboard
  7. View reports on Reports Dashboard
